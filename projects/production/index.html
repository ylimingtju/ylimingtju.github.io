资源配置与协同调度优化

围绕新型生产组织中的资源配置与调度，分别研究多能工参与的 Seru 系统和协作机器人参与的流水车间。两项研究各自建立模型、设计算法并开展实验。

工人只掌握部分技能，产品工序又存在先后关系。人员配置会改变工序的可行分配和处理效率，产品排序也会影响订单完成时间，需要联合决策。

沿用上节的均衡配置，Seru 1 按 A→B、Seru 2 按 C→D 加工。本例每件产品各为一个订单，甘特图给出四个完工时间，合计 TCT = 29。

结果与证据

算例设置共 864 个算例，按产品数量分为小规模（n=5）、中规模（n=8、10）和大规模（n=12、15、20），覆盖 2–4 个 Seru、5–8 名工人及四种技能异质性。以平均 RPD 和平均求解时间比较 SABH、MILP + Gurobi、TS 与 GA；RPD 以各算例比较集中的最好解为参考，GA 未获得可行解的算例按原统计口径排除。

实验结论小规模上，MILP + Gurobi 的平均 RPD 最低；大规模上，SABH 的平均 RPD 为 1.42%，低于 MILP + Gurobi 的 6.14%，平均求解时间为 86.87 秒，后者为 1742.64 秒。两阶段启发式在所测试的大规模算例中兼顾了解质量与求解效率，但不提供全局最优性保证。

02协作机器人流水车间调度

协作机器人可以独立加工，也可以与机器共同加工。机器之间的机器人配置、各工序的处理模式和作业顺序相互影响，决定系统的最大完工时间。

我的工作 独立完成模型、强化方法、混合算法、计算实验及论文撰写。

问题与决策

一台机器人用于独立加工，还是与机器协同，何时更有价值？

资源配置
将有限机器人分配到机器。
处理模式
机器单独、机器人单独或二者协同加工。
作业顺序
协调跨机器先后关系和两类资源占用。

处理模式怎样改变资源占用

求解过程

两机混合启发式 · CGHA

CGHA 联合搜索作业顺序、处理模式与机器人位置：微型遗传算法生成候选，资源解码器构造可行时序，再结合关键路径改进与模拟退火决定是否更新。下图沿用上节的单机局部小例，展开一次模式调整。

一次模式调整如何缩短完工时间

读取当前方案

固定 A→B→C 的解码优先序，三道工序均采用协同模式 C。每道工序同时占用机器与机器人，因此依次加工，Cmax = 13。

结果与证据

算例设置两机主实验共 280 例，作业数为 5–200，机器人数量为 1 或 2；多机实验另有 112 例。MILP 与强化模型 eMILP 使用 Gurobi 12.0，每例限时 1800 秒；CGHA 每例独立运行 3 次，解质量取最好一次，耗时取单次均值。下表按相同作业规模并列展示；两机大规模统一采用 n=50、100，n=200 因 MILP 未找到可行解而未列入。

实验结论eMILP 将两机中规模的平均 Gap 从 33.30% 降至 1.02%，并将多机大规模获得可行解的数量从 35/48 提高到 48/48。CGHA 在全部 280 个两机算例中，有 279 个达到所比较启发式的最好值（含并列），平均 RPD 为 0.0034%，低于其余五种启发式的 8.28%–9.95%；单次平均耗时为 30.39 秒。对于 n=50、100 的 80 例，CGHA 单次平均耗时为 24.65 秒。Gap 与 RPD 的参照不同，不能据此认定 CGHA 优于 eMILP 或已经达到全局最优。

适用范围与比较MILP 与 eMILP 覆盖 m 机系统，CGHA 针对两机情形。表中并列展示三种方法的结果，模型的 Gap 与启发式的 RPD 保留各自参照；CGHA 的解质量取三次最好结果，耗时为单次均值，三次运行的总耗时约为表中数值的三倍。
